# Fonts

These fonts are served from this site instead of Google Fonts, so pages make no request to a third-party font service. Each is licensed under the SIL Open Font License, Version 1.1 (https://openfontlicense.org). The copyright notices below are copied from the fonts' own metadata. The web subsets don't carry the licence text itself, so the full SIL Open Font License 1.1 text should sit next to these files as OFL.txt (see the launch checklist in .github/README.md).

Only the latin and latin-ext subsets are included, downloaded from Google Fonts on 18 Nov 2026.
